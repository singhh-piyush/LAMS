HOW TO RUN LAMS
===============

Full instructions are in README.md. This is the short version for Windows.


BEFORE YOU START
----------------
Install these, then close and reopen Command Prompt:

  - Node.js       https://nodejs.org              (the LTS button)
  - PostgreSQL    https://www.postgresql.org/download/windows

Write down the PostgreSQL password you choose during install. You need it below.


SETUP
-----
Open Command Prompt and run these one at a time:

    git clone https://github.com/singhh-piyush/LAMS.git
    cd LAMS\LAMS
    npm install
    copy .env.example .env
    notepad .env

In Notepad, change this one line to your PostgreSQL password, then save and close:

    DB_PASSWORD=your_postgres_password_here

Then:

    npm run setup-db
    npm start

Open http://localhost:3000

Log in with 25116045 (student) or TECH001 (technician).
Password for every test account: Password123

Ctrl + C stops the server. "npm start" starts it again.
"npm run setup-db" resets the demo data - do this before presenting.

On Mac or Linux everything is the same, except use "cp .env.example .env"
instead of "copy", and any text editor instead of notepad.


EMAIL - OPTIONAL
----------------
You do not need to set this up. By default MAIL_TRANSPORT=console, so pressing
"Forgot your password?" prints the reset link into the Command Prompt window.
Copy it into the browser and it works.

If you want the email to land in a real inbox you can look at, see the
"Email setup (Mailtrap)" section in README.md. It is a free account and takes
about two minutes. Mailtrap's sandbox catches the mail so nothing is ever
delivered to an actual person.


TROUBLESHOOTING
---------------
"'git' is not recognized"
    Git is not installed. https://git-scm.com/download/win

"'npm' is not recognized"
    Node.js is not installed, or Command Prompt was already open when you
    installed it. Close it and open a new one.

"Cannot find module 'express'"
    You skipped npm install, or ran it in the wrong folder. It belongs in the
    folder that has package.json in it.

"Could not connect to PostgreSQL"
    PostgreSQL is not running, or DB_PASSWORD in .env is wrong.

"Database: NOT CONNECTED" when the server starts
    Run npm run setup-db first.

"Port 3000 already in use"
    Change PORT in .env, and change BASE_URL to match.

The page loads but every table is empty
    The database exists but was never filled. Run npm run setup-db.


DOING THE DATABASE BY HAND
--------------------------
"npm run setup-db" does it for you, but if you would rather:

  - create a database called lams_db
  - open a Query Tool against it
  - paste and run the whole of lams_database_setup.sql
