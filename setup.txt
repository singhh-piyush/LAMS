HOW TO RUN LAMS
===============

The full instructions are in README.md, at the top under "Running it on your own machine".

Short version:

  1. Install Node.js (nodejs.org, LTS) and PostgreSQL (postgresql.org/download).
     Remember the PostgreSQL password you set during install.

  2. Clone the repository and open a terminal in the inner LAMS folder - the one
     with package.json in it:

        git clone https://github.com/singhh-piyush/LAMS.git
        cd LAMS/LAMS
        npm install

  3. Copy .env.example to .env and put your PostgreSQL password in DB_PASSWORD.

        Windows:   copy .env.example .env
        Mac/Linux: cp .env.example .env

  4. Create and fill the database:

        npm run setup-db

  5. Start it:

        npm start

  6. Open http://localhost:3000

DOING THE DATABASE BY HAND
--------------------------
"npm run setup-db" does both steps for you and is less error-prone, but if you would
rather do it yourself:

  - create a database called lams_db
  - open a Query Tool against it
  - paste and run the whole of lams_database_setup.sql


TROUBLESHOOTING
---------------
"Cannot find module 'express'"
    You skipped step 2, or ran npm install in the wrong folder. It belongs in the
    inner LAMS folder, next to package.json.

"Could not connect to PostgreSQL"
    PostgreSQL is not running, or DB_USER / DB_PASSWORD in .env are wrong.

"Database: NOT CONNECTED" when the server starts
    Run npm run setup-db first.

Port 3000 already in use
    Change PORT in .env, and BASE_URL to match.

The page loads but every list is empty
    The database exists but was never filled. Run npm run setup-db.
